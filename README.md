# RED LEGACY — Premium Manchester United React Fan Experience

Premium React/Vite fan-site concept built for GitHub Pages.

## Browser-only GitHub deployment

1. Create a new GitHub repository.
2. Upload **everything in this folder** using GitHub's browser upload.
3. Commit to the `main` branch.
4. Open **Actions** and wait for **Deploy Red Legacy to GitHub Pages** to finish.
5. Open **Settings → Pages** and select **GitHub Actions** as the source if GitHub asks.
6. GitHub publishes the site automatically.

You do not need to run npm, Vite, React or a terminal yourself.

## Real footage and photographs

The project does not bundle copyrighted Manchester United match footage or unlicensed photographs.

Place licensed video files in:

`public/videos/penalty-01.mp4` through `public/videos/penalty-10.mp4`

For real manager photographs, use properly licensed images and replace the visual placeholders in the React UI.

## Important

This is an independent/unofficial fan project. Manchester United names, marks, photographs and match footage remain the property of their respective owners.

The VIP area is a front-end demonstration. A real paid membership system needs secure authentication, a backend/database and a payment provider.

The Matchday page deliberately does not provide unauthorized live streams. Add only streams/content you have the rights to distribute.
